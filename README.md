# Dacitos Technologies — Modern IT Agency Platform

A modern, high-performance IT consulting and agency website built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**. Designed with dark glassmorphic UI aesthetics, smooth scroll animations, and interactive component architecture.

---

## 🚀 Features & Overview

- **Hero & Services Grid:** Interactive service cards with custom gradient glow borders and status badges.
- **Interactive Process & Values Canvas:** Dynamic tab switching for core business pillars and horizontal execution timeline.
- **Filterable Testimonials:** Dynamic category-based filtering displaying client reviews and measurable outcome metrics.
- **Project Inquiry & CTA:** Glassmorphic consultation booking form with integrated trust badges.
- **Responsive Footer:** Multi-office address display, quick links, government MCA registration badge, and working newsletter subscription form.
- **Custom 404 Page:** Sleek, animated error page designed to route users back home smoothly.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icon Library:** [Lucide React](https://lucide.dev/)
- **Language:** JavaScript (ES6+)

---

## 💻 Installation & Setup

Follow these steps to run the project locally on your machine:

### 1. Clone the Repository
```bash
git clone [https://github.com/your-username/dacitos-technologies.git](https://github.com/your-username/dacitos-technologies.git)
cd dacitos-technologies

```

### 2. Install Dependencies

```bash
npm install
# or
yarn install
# or
pnpm install

```

### 3. Run the Development Server

```bash
npm run dev
# or
yarn dev
# or
pnpm dev

```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
